9-1GDP 的含义（四个关键词）★★★名词解释 / 选择
大白话

GDP 就是：一段时间内，在一个国家的地盘上，新生产出来、并且卖给"最终用户"的那些东西，按市场价格加起来一共多少钱。四个限定词缺一不可。

记忆法
口诀：市值 · 最终 · 境内 · 流量　→　联想"钱，最终在境内流动"

① 市值：按市场价算，不是按成本、也不是按"幸福感"；② 最终：只算最终产品，中间品不算（防重复计算）；③ 境内：按国土原则（在中国境内生产就算中国的，不管老板是哪国人）；④ 流量：是一段时期内的量，不是某一时点的存量。

公式
GDP = Σ（某最终产品的市场价格 × 该产品的产量）
易错

下面这些都不计入 GDP：中间产品（轮胎卖给汽车厂）、二手货交易（二手房、二手车本身，但中介费算）、自己做家务、股票债券买卖（只是资产换手）、政府转移支付（养老金、救济金，没对应生产）、纯金融资产交易。

对照：计入的——新建住房（算投资）、存货增加（算存货投资）、家政保姆工资（市场化的服务）、政府雇员工资（政府购买）。

9-2GDP 的三种核算方法★★★计算 / 简答
大白话

同一块蛋糕，三种切法：看谁买了（支出法）、看谁赚了（收入法）、看谁造的（生产法/增值法）。理论上三种结果相等，实际会有"统计误差"。

记忆法
支出法记 C + I + G + NX　→　"消 · 投 · 政 · 净"（老百姓花、企业投、政府买、外国人净买） 收入法记"打工拿工资、借钱收利息、出租收租金、老板拿利润，再补上折旧和间接税减补贴" 生产法记"每个行业只算自己增加的那部分价值"（总产出 − 中间投入），所以又叫增值法
公式
支出法：GDP = C（消费） + I（投资） + G（政府购买） + NX（净出口 = X − M） 收入法：GDP = 工资 + 利息 + 租金 + 利润 + 折旧 + 间接税 − 补助金 生产法：GDP = Σ（各部门总产出 − 各部门中间投入） = Σ 增加值

投资 I 里的坑：买机器设备算投资，盖新房算投资，存货增加也算投资；但买股票债券不算投资（那是金融资产，不是新生产的资本品）。

易错

① 政府购买 G 不含转移支付；② 净出口是"出口减进口"，进口要减掉（因为 C、I、G 里可能含进口品，要剔除外国产的）；③ 支出法里的"投资"是总投资（含折旧重置），不是净投资。

9-3名义 GDP、实际 GDP 与 GDP 平减指数★★★计算
大白话

名义 GDP：用当年价格算的产值（产量涨、价格涨，它都会涨，分不清）。
实际 GDP：用基年价格算的产值（把价格变动"冻住"，只看产量变没变）。
GDP 平减指数：名义 ÷ 实际，反映"价格涨了多少"。

记忆法
"名义跟着价格跑，实际只认货多少"

算实际 GDP 就一句话：永远拿基年的价格 × 当年的产量。基年一变，实际 GDP 数值也变（但增长率不变）。

公式
名义 GDP = Σ（当年价格 Pt × 当年产量 Qt） 实际 GDP = Σ（基年价格 P基期 × 当年产量 Qt） GDP 平减指数 = （名义 GDP ÷ 实际 GDP） × 100　　　教材式（9.3） 实际 GDP = （名义 GDP ÷ 平减指数） × 100　　　　　教材式（9.4）

计算技巧：平减指数本质是"现价篮子 ÷ 基价篮子"，所以基年的平减指数一定 = 100。做题时先算名义，再算实际，最后相除，三步走不会乱。

易错

基年选错最致命——题目说"以 2018 年为基期"，就必须用 2018 年的价格去乘以后各年的产量。另外，实际 GDP 的数值依赖基年，但增长率不依赖。

9-4CPI、PPI 与通货膨胀率★★★计算 / 简答
大白话

CPI：盯住老百姓固定买的那"一篮子"东西，看这篮子今年比基年贵了多少。
PPI：盯住企业出厂的批发价。
通货膨胀率：就是价格指数的百分比涨幅。

记忆法
"CPI 是百姓的菜篮子，平减指数是自家全产出"　→　菜篮子固定，自家产出随产量变

专业点说：CPI 用拉氏指数（固定基期数量），平减指数用帕氏指数（用当期数量）。考试常问"两者为何不同"，就答这一句。

公式
CPI = （固定篮子按当期价格的费用 ÷ 同一篮子按基期价格的费用） × 100 通货膨胀率 π = （CPIt − CPIt−1） ÷ CPIt−1 × 100%
易错

CPI 与平减指数三大区别（简答常考）：① 篮子：CPI 固定，平减指数随产量结构变；② 范围：CPI 含进口消费品、不含投资品和政府购买，平减指数只含国内生产的全部最终产品；③ 因此 CPI 常高估生活成本上升（没考虑替代、质量改进、新商品）。

9-5失业的衡量：劳动力、失业率、参与率★★★计算
大白话

成年人被分成三类：就业者（有活干）、失业者（没活干但正在找）、非劳动力（不找活：学生、退休、丧失信心的）。劳动力 = 就业 + 失业，没在找工作的人不算失业。

记忆法
当失业者要满足三件事："没活干 + 想干活 + 正在找"　→　三缺一就不算失业 失业率 + 就业率 = 1（因为分母都是劳动力），知道一个就能推出另一个
公式
劳动力人数 = 就业人数 + 失业人数　　　　　　（9.7） 失业率 = 失业人数 ÷ 劳动力人数 × 100%　　　　（9.8） 就业率 = 就业人数 ÷ 劳动力人数 × 100%　　　　（9.9） 劳动力参与率 = 劳动力人数 ÷ 劳动年龄人口数 × 100%
易错

① "丧失信心的劳动者"（放弃找工作的）退出劳动力，会使失业率下降——这是失业率"看起来变好"的陷阱；② 分母是劳动力，不是"总人口"也不是"劳动年龄人口"（算参与率时才用后者）。

9-6失业的三种类型与自然失业率★★★简答 / 名词解释
大白话

摩擦性失业：在"换工作/找工作"的路上（信息不通、地域不匹配），短期、正常。
结构性失业：技能对不上岗位，或者工资被最低工资法、工会抬得太高降不下来，长期、难治。
周期性失业：经济冷了，岗位整体变少——这才是宏观经济学要治的对象。

记忆法
"摩擦＝在路上（换），结构＝配不上（僵），周期＝没岗位（冷）" "摩擦 + 结构 = 自然失业率（治不好的那部分），再加上周期性的，就是实际失业率"
公式
实际失业率 = 摩擦性失业率 + 结构性失业率 + 周期性失业率 　　　　　 = 自然失业率 + 周期性失业率　　（9.11）
易错

充分就业 ≠ 零失业，而是"周期性失业为零"，此时失业率 = 自然失业率。考题常在这里挖坑。

9-7潜在 GDP 与 GDP 缺口★★名词解释
大白话

潜在 GDP：现有资本和技术下，把人（劳动力）充分用起来能产出的量，也就是"满负荷产量"。GDP 缺口 = 实际 − 潜在：为负说明经济偏冷、有资源闲置。

记忆法
"潜在 = 充分就业时的实际 GDP"；"缺口为负 = 衰退缺口，缺口为正 = 通胀缺口"
公式
GDP 缺口 = 实际 GDP − 潜在 GDP 产出缺口率 = （实际 GDP − 潜在 GDP） ÷ 潜在 GDP × 100%
易错

短期总产出主要由就业量决定（资本、技术短期不变），所以失业率一上去，实际 GDP 就掉到潜在水平之下——这正是奥肯定律（第十三章）的由来。

9-8四大宏观经济问题：失业、通胀、滞胀、增长★★简答
大白话

宏观经济学要解决的四个问题，正好对应四大指标：失业（就业指标）、通货膨胀（价格指标）、滞胀（两个指标同时坏：高失业 + 高通胀）、增长（产量指标长期向上）。

记忆法
"滞胀 = 停滞 + 通胀"（stagflation）　→　"又贵又没人要，还裁人"

滞胀是供给冲击（如石油涨价）造成的，用需求政策治不了——治通胀会加深衰退，治衰退会加剧通胀。这在第十二、十三章会详细考。

9-9流量与存量★选择 / 名词解释
大白话

存量：某一时点上的量（像照片）——财富、资本存量、失业人数。流量：某一时期内的量（像录像）——收入、GDP、投资。

记忆法
"存量看时点（照片），流量看时段（录像）"；"投资（流量）会变成资本（存量）"
易错

经典坑：GDP 是流量，不是存量；"某人有 100 万存款"是存量，"他一年挣 20 万"是流量。

9-10GDP 指标的局限（本章评析）★★论述
大白话

GDP 只是"生产了多少"的账本，不是"过得好不好"的成绩单。家务劳动、地下经济、闲暇、环境破坏、收入分配，它全都不记。

记忆法
五个"不算"：不算家务、不算地下、不算闲暇、不算环境、不算分配

答题模板：先肯定（GDP 是衡量产出的最综合指标，便于国际比较和判断宏观形势）→ 再列局限（五不算 + 不能反映质量与结构）→ 最后补一句（应结合其他指标综合判断，不能唯 GDP 论）。

例 1计算支出法核算 GDP

某国一年内的资料如下（单位：亿元）：居民消费 5000；企业固定资产投资 1200；存货增加 300；政府购买商品和服务 1800；政府发放养老金 500；出口 1200；进口 1000；居民购买新建住房 400。求该国 GDP，并说明哪些项目不计入。

展开答案与解析

认变量：支出法四件套 C、I、G、NX。注意"新建住房"属于投资，"养老金"属于转移支付。

C = 5000

I = 固定资产投资 1200 + 存货增加 300 + 新建住房 400 = 1900

G = 1800（不含养老金 500，那是转移支付，没有对应生产）

NX = X − M = 1200 − 1000 = 200

GDP = 5000 + 1900 + 1800 + 200 = 8900 亿元

答案：GDP = 8900 亿元。不计入的：政府养老金 500（转移支付）。若题中再出现"购买股票 200""二手房交易 300""自己做家务"也一律不计入。
技巧：做支出法的题，先把每个数字贴标签（C/I/G/NX/不计入），加总即可。最容易丢分的两处：忘记存货增加算投资、把转移支付误当成政府购买。
例 2计算名义 GDP、实际 GDP 与平减指数

某经济只生产苹果和橘子。基年（2018）：苹果 5 元/斤、产 100 斤；橘子 4 元/斤、产 200 斤。2020 年：苹果 6 元/斤、产 120 斤；橘子 5 元/斤、产 220 斤。以 2018 年为基期，求 2020 年的名义 GDP、实际 GDP、GDP 平减指数，以及 2020 年相对 2018 年的价格涨幅和实际产量增幅。

展开答案与解析

2018 年（基年）：名义 GDP = 5×100 + 4×200 = 500 + 800 = 1300；实际 GDP 同为 1300（基年名义=实际）。

2020 年名义 GDP（用当年价格）= 6×120 + 5×220 = 720 + 1100 = 1820

2020 年实际 GDP（用基年价格）= 5×120 + 4×220 = 600 + 880 = 1480

平减指数 = 1820 ÷ 1480 × 100 ≈ 123

价格涨幅 = 123 − 100 = 23%；实际产量增幅 = 1480 ÷ 1300 − 1 ≈ 13.8%

答案：名义 GDP 1820，实际 GDP 1480，平减指数 ≈123，物价上涨 23%，实际产出增长 13.8%。
技巧：名义与实际只差"用哪年的价格"——名义用当年价，实际用基年价，产量永远用当年。把这句话写在草稿纸上，这类题再也不会错。
例 3计算 + 简答CPI 与平减指数为何不同

沿用上题数据。假设消费者固定篮子为"3 斤苹果 + 2 斤橘子"，基年为 2018 年。计算 2020 年的 CPI 与通货膨胀率，并解释它为什么与平减指数（123）不相等。

展开答案与解析

基年篮子费用 = 5×3 + 4×2 = 15 + 8 = 23

2020 年同一篮子费用 = 6×3 + 5×2 = 18 + 10 = 28

CPI = 28 ÷ 23 × 100 ≈ 121.7；通货膨胀率 ≈ 21.7%

答案：CPI ≈ 121.7，通胀率 ≈ 21.7%。与平减指数 123 不同，原因在于：CPI 用固定的基期篮子（拉氏指数），而平减指数用当期产量结构（帕氏指数）。本题中橘子（相对便宜、消费量大）产量占比上升，使按当期产量加权的平减指数略高于固定篮子的 CPI。
技巧：CPI 计算永远三步：基期篮子多少钱 → 当期同一篮子多少钱 → 后者除以前者 ×100。篮子里的数量永远不变，只有价格在变。
例 4计算失业率与劳动参与率

某国劳动年龄人口 1.2 亿，其中：就业 7200 万；正在积极找工作 400 万；因找不到工作已放弃寻找 100 万；其余为全日制学生与退休人员。求劳动力人数、失业率、就业率、劳动力参与率。若那 100 万"丧失信心者"全部重新开始找工作（且尚未找到），失业率变为多少？

展开答案与解析

劳动力 = 就业 7200 + 失业 400 = 7600 万（放弃找工作者不计入劳动力）

失业率 = 400 ÷ 7600 × 100% ≈ 5.26%；就业率 = 7200 ÷ 7600 ≈ 94.74%（两者相加 = 1）

参与率 = 7600 ÷ 12000 × 100% ≈ 63.3%

若 100 万人回来找工作：劳动力 = 7200 + 500 = 7700 万，失业率 = 500 ÷ 7700 ≈ 6.49%

答案：劳动力 7600 万，失业率 5.26%，就业率 94.74%，参与率 63.3%；丧失信心者回归后失业率升至 6.49%。
记忆要点：放弃找工作的人"退出劳动力"，会人为压低失业率。所以看到"失业率下降"别急着高兴，要问一句：是因为找到工作了，还是因为不找了？
例 5简答充分就业与自然失业率

某国摩擦性失业率 2%，结构性失业率 3%，周期性失业率 1.5%。（1）求自然失业率和实际失业率；（2）该国是否实现了充分就业？为什么？

展开答案与解析

自然失业率 = 摩擦性 + 结构性 = 2% + 3% = 5%

实际失业率 = 自然失业率 + 周期性 = 5% + 1.5% = 6.5%

答案：（1）自然失业率 5%，实际失业率 6.5%；（2）没有实现充分就业——因为周期性失业率不为零（1.5%）。充分就业只要求"周期性失业 = 0"，摩擦性和结构性失业依然存在，所以充分就业时失业率 = 自然失业率 = 5%，而非 0。
例 6判断 / 选择GDP 口径辨析

判断下列项目是否计入当年中国 GDP，并说明理由：（1）面包厂卖给超市的面粉；（2）家庭主妇在家做饭；（3）某人花 20 万买入贵州茅台股票；（4）某美资企业在上海生产的汽车；（5）政府给低保户发放的补助金；（6）二手房中介收取的 2 万元佣金。

展开答案与解析
（1）不计入——中间产品，价值已包含在最终产品（面包）中，计入会重复计算。
（2）不计入——非市场性活动，没有市场交易价格。
（3）不计入——金融资产交易，只是所有权转移，不是当期生产。
（4）计入——按国土原则，在中国境内生产即计入中国 GDP（与老板国籍无关）。
（5）不计入——政府转移支付，没有对应的当期生产与服务交换。
（6）计入——中介提供了当期服务，佣金是服务的市场价值（但房屋本身价值不计入）。
技巧：判断计入与否只需问一句——"今年有没有新生产出东西、并且按市价卖给了最终用户？"能答"是"就计入，否则不计入。

10-1均衡国民收入的决定原理★★★简答 / 计算
大白话

企业按某个规模生产，结果生产出来的正好全卖掉了（没出现意外的库存积压，也没供不应求），企业就不会改变产量——这个产量就是均衡国民收入。判别标准只有一条：非计划存货投资 = 0。

记忆法
"生产 = 卖掉，没有意外积压"；图形上就是 AE 线与 45° 线的交点

45° 线上的每一点都满足"支出 = 收入"，所以 AE 曲线和它相交的那一点才既是"想买的量"又是"生产的量"。

公式
均衡条件：Y = AE（总支出 = 总产出） 等价说法：计划投资 = 计划储蓄（I = S）　或　非计划存货投资 = 0 若 AE > Y（想买的比生产的多）→ 意外动用库存 → 企业扩产 → Y 上升 若 AE < Y（卖不掉）　　　　　→ 库存意外积压 → 企业减产 → Y 下降

计算技巧：把 AE 写成"常数 + 系数×Y"的形式，再令 AE = Y 解一元一次方程，秒出答案。

10-2消费函数与消费倾向★★★计算 / 名词解释
大白话

α（自发消费）：就算一分钱不挣也要花的钱（动用储蓄或借债），是"保底消费"。
β（边际消费倾向 MPC）：每多挣 1 块钱，拿出来花掉的比例（比如 0.8 就是多挣 1 块花 8 毛）。

记忆法
"α 是保底花，β 是增量花"；"边际看增量（ΔC/ΔY），平均看总账（C/Y）" 必背等价关系：MPC + MPS = 1；APC + APS = 1；C + S = Y
公式
消费函数：C = α + βY　　（α > 0，0 < β < 1） MPC = ΔC / ΔY = β　　　　APC = C / Y = α/Y + β 储蓄函数：S = Y − C = −α + (1 − β)Y MPS = ΔS / ΔY = 1 − β　　APS = S / Y

做题套路：给一张收入—消费表，先算 β = ΔC/ΔY，再算 α = C − βY；给函数式就直接读 α、β。

易错

① 因为 α > 0，所以 APC > MPC（且收入越高 APC 越接近 β）；② 消费曲线与 45° 线的交点是收支相抵点（S = 0），交点左边是负储蓄（C > Y，动用存款或借债），右边才有正储蓄。

10-3其他消费理论（相对收入 / 生命周期 / 持久收入）★★简答
大白话

相对收入（杜森贝利）：消费不光看自己挣多少，还看邻居挣多少（示范效应），以及自己过去的最高水平（棘轮效应：由俭入奢易、由奢入俭难）。
生命周期（莫迪利安尼）：人一辈子平滑消费——年轻借钱、中年储蓄、老年花储蓄。
持久收入（弗里德曼）：只看"长期平均收入"，临时奖金基本不花。

记忆法
"相对收入＝爱攀比 + 下不来（棘轮）　→　"棘轮"想象成只能往上推、退不回来的齿轮" "生命周期＝一辈子拉平；持久收入＝只看长期平均"

三者共同意义：短期消费不只由当期收入决定 → 解释"短期消费函数不稳定、长期消费函数稳定"的谜团。

10-4投资函数与资本边际效率★★★计算 / 名词解释
大白话

投资函数：利率越高，借钱搞项目越贵，投资越少 —— 所以投资是利率的减函数。
资本边际效率（MEC）：让一个投资项目"刚好不赚不赔"的那个贴现率（类似内部收益率）。

记忆法
"利率是借钱的价格，价格贵就少买（少投资）" → 投资曲线 i = e − dr 向右下倾斜 投资决策规则：资本边际效率 > 市场利率 → 值得投；反之不投
公式
投资函数：i = e − d·r　　（e：自发投资，d：投资对利率的敏感系数） 资本边际效率：使 Σ Rt/(1+MEC)t = 资本品价格 成立的贴现率 托宾 q = 企业的股票市场价值 ÷ 资本重置成本　　q > 1 → 值得投资
易错

d 越大＝投资对利率越敏感；这个 d 后面在 IS—LM 里决定 IS 曲线的平缓程度（越敏感越平缓），也决定挤出效应大小，是贯穿两章的关键参数。

10-5两部门 / 三部门 / 四部门均衡收入★★★计算
大白话

两部门＝只有居民和企业；三部门＝加政府（收税、买东西）；四部门＝再加外国人（出口、进口）。部门越多，漏出（储蓄、税收、进口）越多，同样的支出能"滚"出来的收入就越小。

记忆法
"分母就是 1 − 边际支出倾向 + 漏出倾向"：两/三部门分母 1−β；四部门分母 1−β+γ（γ＝边际进口倾向） "凡是要经过老百姓的手才花出去的，都要乘一个 β（税收、转移支付）；政府自己直接买的，不用乘"
公式
两部门：Y = C + I，C = α + βY　→　Y = （α + I）/（1 − β） 三部门（定量税）：C = α + β（Y − T + TR） 　　　Y = （α + I + G + β·TR − β·T）/（1 − β） 三部门（比例税 T = tY）：Y = （α + I + G + β·TR）/［1 − β（1 − t）］ 四部门：NX = X − M，M = M0 + γY 　　　Y = （α + I + G − βT + βTR + X − M0）/（1 − β + γ）

技巧：别死记公式，掌握做法——把 C、I、G、NX 全写成 Y 的表达式 → 加总成 AE → 令 AE = Y → 解方程。这样任何变体（比例税、进口函数、投资补贴）都能现场推导。

10-6乘数原理（全套乘数公式）★★★计算 / 论述
大白话

我多花 100 块买你的东西 → 你多挣 100 块 → 你拿出 80 块（β=0.8）买别人的 → 别人多挣 80 → 再花 64……一轮一轮滚下去，最初那 100 块最终让整个经济的收入增加了 500 块。这个"放大倍数"就是乘数。

记忆法
"花得越多（β 越大），漏得越少，乘数越大"，1/(1−β) = 1/MPS——存得越少，滚得越猛 四类乘数一张表：投资、政府购买 = 1/(1−β)；转移支付 = β/(1−β)；税收 = −β/(1−β)；平衡预算 = 1 记忆窍门：税收乘数比转移支付乘数只多一个负号（一个抽钱一个给钱，力度一样方向相反）
公式
投资乘数 ki = 政府购买乘数 kg = 1 /（1 − β）= 1 / MPS 转移支付乘数 ktr = β /（1 − β）　　　（比政府购买乘数小，差一个 β） 税收乘数 kt = − β /（1 − β）　　　　（负号：加税压收入，减税拉收入） 平衡预算乘数 kb = 1　　　　　　　　（ΔG = ΔT 时，ΔY = ΔG） 四部门外贸乘数 = 1 /（1 − β + γ） 比例税下的乘数 = 1 /［1 − β（1 − t）］　　　（漏出更多 → 乘数更小）

算多变量变化时：ΔY = 各个乘数 × 各自的变化量，然后相加（线性可叠加）。

易错

① 政府购买乘数大于转移支付乘数：因为政府买东西是直接形成需求，而发钱给居民后，居民只花掉 β 部分（剩下存起来了）——这就是为什么"政府搞基建"比"直接发钱"拉动 GDP 更猛（模型内结论）。
② 平衡预算乘数 = 1 的前提是定量税；比例税下它小于 1。

10-7节俭悖论★★简答
大白话

人人都想多存钱 → 没人买东西 → 企业卖不掉就减产裁员 → 大家收入下降 → 最后反而存不下钱。个人理性导致集体非理性。

记忆法
"人人存钱 → 没人买 → 收入降 → 存不成"（越省越穷，越花越富——仅适用于萧条、资源闲置时）
易错

节俭悖论只在有效需求不足、资源大量闲置时成立；若经济已在充分就业状态（供给受限），多储蓄 → 利率降 → 投资增，节俭反而有利。答题时一定要加这个前提限定。

10-8投资 q 理论与影响预期收益的因素★名词解释
大白话

托宾 q：股票市场对这家公司的估值 ÷ 重新买一套同样的设备要花的钱。q > 1 说明"市场说它值钱，比买新设备还贵" → 值得新增投资。

记忆法
"q > 1，多盖厂；q < 1，别扩张"（股市火 → 投资旺的传导链条）
10-9影响消费的其他因素★简答
大白话

除了收入，消费还受利率、价格水平、收入分配、财富、社会保障、信贷条件影响。

记忆法
六字诀："利 · 价 · 分 · 富 · 保 · 贷"（利率、物价、分配、财富、社保、信贷）

答题提示：利率对消费的影响是双向的（替代效应：利率高→少花多存；收入效应：利率高→利息收入多→多花），所以理论上方向不明确——这个"不确定"本身就是得分点。

10-10乘数发挥作用的前提与局限★★论述
大白话

乘数要"滚"起来，前提是经济里还有闲置资源——有失业工人、有空闲产能，多出来的需求才能变成多出来的产量。若已经满负荷，需求增加只会变成涨价，产量不增。

记忆法
"有闲人闲机器，乘数才灵；满负荷再加需求，只会涨价"

其他局限：漏出（储蓄、税收、进口）会削弱乘数；传导有时滞；本章模型假设价格、利率不变，现实中两者都会变（这正是下一章 IS—LM 要解决的）。

10-11本章评析要点★论述
大白话

凯恩斯这个"需求决定收入"的框架，重需求、轻供给，适合萧条时期；但它忽略了供给侧约束、价格与利率的反馈、预期和制度因素，长期增长不能靠它解释。

记忆法
答题三段式：先肯定（解释短期波动、有效需求不足很有效）→ 再指出局限（价格利率不变假设、忽视供给与预期）→ 最后结合中国实际（宏观调控既要扩内需也要供给侧结构性改革）

例 1计算两部门均衡收入与消费、储蓄

两部门经济中，消费函数 C = 300 + 0.75Y，投资 I = 500。求：（1）均衡国民收入；（2）此时的消费与储蓄；（3）投资乘数。

展开答案与解析

写方程：AE = C + I = 300 + 0.75Y + 500 = 800 + 0.75Y

令 AE = Y：Y = 800 + 0.75Y → 0.25Y = 800 → Y = 3200

C = 300 + 0.75×3200 = 300 + 2400 = 2700；S = Y − C = 3200 − 2700 = 500

验证：S = −α + (1−β)Y = −300 + 0.25×3200 = 500，且 S = I = 500 ✓

乘数 = 1/(1−0.75) = 4

答案：均衡收入 3200，消费 2700，储蓄 500，投资乘数 4。
技巧：两部门题有个免费验算器：均衡时 S = I。算出 Y 后代回储蓄函数，若等于 I，就一定没算错。
例 2计算投资乘数的运用

接上题。若企业自主投资由 500 增加到 600，求新的均衡收入与收入增量，并与乘数计算结果对照。

展开答案与解析

乘数法：ΔY = k × ΔI = 4 × 100 = 400 → 新均衡 Y = 3200 + 400 = 3600

方程法验证：Y = (α + I)/(1−β) = (300 + 600)/0.25 = 900/0.25 = 3600 ✓

其中消费增加 ΔC = β × ΔY = 0.75 × 400 = 300

答案：新均衡收入 3600，增加 400。
技巧：见到"某某增加 Δ，求收入增加多少"——直接乘数 × Δ 一步到位，不必重解整个方程；但第一次做题建议用方程法验一遍，考试时再用快捷法省时间。
例 3计算三部门均衡收入与各类乘数

三部门经济：C = 200 + 0.8(Y − T + TR)，定量税 T = 250，转移支付 TR = 50，投资 I = 300，政府购买 G = 400。求：（1）均衡国民收入；（2）政府购买乘数、税收乘数、转移支付乘数、平衡预算乘数；（3）若政府购买增加 100，新均衡收入是多少？

展开答案与解析

写 AE：C = 200 + 0.8(Y − 250 + 50) = 200 + 0.8Y − 160 = 40 + 0.8Y

AE = C + I + G = 40 + 0.8Y + 300 + 400 = 740 + 0.8Y

令 AE = Y：Y = 740 + 0.8Y → 0.2Y = 740 → Y = 3700

β = 0.8 → 政府购买乘数 = 1/(1−0.8) = 5；税收乘数 = −0.8/0.2 = −4；转移支付乘数 = 4；平衡预算乘数 = 1

ΔG = 100 → ΔY = 5 × 100 = 500 → 新 Y = 4200（验证：AE = 740 + 100 + 0.8Y → Y = 840/0.2 = 4200 ✓）

答案：（1）Y = 3700；（2）5、−4、4、1；（3）Y = 4200。
技巧：三部门题最容易错在"可支配收入"——记住消费函数里的收入是 Yd = Y − T + TR，减税加转移。把这一项先化简成"常数 + 0.8Y"，后面就只是解一元一次方程了。
例 4计算平衡预算乘数的验证

承上题（β = 0.8）。政府同时增加购买 100 和增加等额税收 100（即 ΔG = ΔT = 100）。求收入变动，并说明为什么平衡预算乘数等于 1。

展开答案与解析

扩张效应：ΔG = 100 → ΔY₁ = 5 × 100 = +500

紧缩效应：ΔT = 100 → ΔY₂ = (−4) × 100 = −400

合计：ΔY = 500 − 400 = +100 = ΔG

答案：收入净增 100，正好等于政府支出增量，故平衡预算乘数 = 1。直觉解释：政府收上来的 100 块钱，本来会被居民花掉 80 块（β=0.8）；政府把这 100 块全部花出去，等于"把居民没花的那 20 块也花了"，净增加的需求刚好是 100 × (1 − β) × 乘数 = 20 × 5 = 100。
记忆："政府多收 100 又多花 100，GDP 就净多 100"——这条结论记住，选择题直接秒选。
例 5计算比例税下的乘数（自动稳定器）

承上题，但税收改为比例税 T = 0.25Y（t = 0.25），其余不变（β = 0.8，TR = 50，I = 300，G = 400）。求均衡收入与政府购买乘数，并说明为什么乘数变小了。

展开答案与解析

可支配收入 Yd = Y − 0.25Y + 50 = 0.75Y + 50

C = 200 + 0.8(0.75Y + 50) = 200 + 0.6Y + 40 = 240 + 0.6Y

AE = 240 + 0.6Y + 300 + 400 = 940 + 0.6Y → Y = 940/0.4 = 2350

政府购买乘数 = 1/［1 − β(1 − t)］ = 1/［1 − 0.8×0.75］ = 1/0.4 = 2.5

答案：均衡收入 2350，政府购买乘数 2.5。乘数从 5 降到 2.5，是因为收入每增加一元就自动被税收抽走 0.25 元，漏出变大、放大效应变小 —— 这正是比例税作为自动稳定器的作用机理（经济过热时自动降温，衰退时自动托底）。
技巧：凡是比例税，就把公式里的 β 换成 β(1−t)，其余照抄。1 − β(1−t) 这个分母要背熟。
例 6计算四部门均衡与外贸乘数

在例 3 的基础上加入国外部门：出口 X = 200，进口函数 M = 100 + 0.1Y（γ = 0.1）。求均衡国民收入与外贸乘数。

展开答案与解析

C = 40 + 0.8Y（同例 3）；NX = X − M = 200 − (100 + 0.1Y) = 100 − 0.1Y

AE = C + I + G + NX = (40 + 0.8Y) + 300 + 400 + (100 − 0.1Y) = 840 + 0.7Y

令 AE = Y：Y = 840 + 0.7Y → 0.3Y = 840 → Y = 2800

外贸乘数 = 1/(1 − β + γ) = 1/(1 − 0.8 + 0.1) = 1/0.3 ≈ 3.33

答案：均衡收入 2800，外贸乘数约 3.33。比三部门的 5 小——因为收入上升会带来进口漏出，本国的支出有一部分"漏"去买外国货了。
技巧：四部门题记住分母 1 − β + γ：β 越大乘数越大（爱花钱），γ 越大乘数越小（爱买洋货）。
例 7简答节俭悖论与乘数前提

"节俭是一种美德，但对于宏观经济可能是灾难。"请结合收入—支出模型评析这一说法。

展开答案与解析

传导链条：人人增加储蓄 → 自发消费 α 下降、β 下降 → 消费曲线下移 → 总支出 AE 下降 → 均衡收入按乘数倍收缩。

关键点：均衡时 S = I 且投资由外生给定 → 储蓄意愿上升并不能提高实际储蓄量，收入下降后实际储蓄反而回到原来的水平（甚至更低）。

答案要点：① 在有效需求不足、资源大量闲置时，节俭会压低总需求并通过乘数收缩产出，形成"越省越穷"的节俭悖论；② 但该结论只在萧条期成立——若经济已处于充分就业（供给受限），储蓄增加会压低利率、刺激投资，促进资本积累与长期增长；③ 因此评价节俭要看经济状态，不能一概而论；④ 政策含义：萧条时应鼓励消费与投资（扩内需），充分就业时则应鼓励储蓄与供给能力建设。

11-1IS 曲线的含义与推导★★★推导 / 计算
大白话

利率越高 → 投资越少 → 总需求越少 → 均衡收入越低。所以利率和收入是反着走的，把每一个利率对应的均衡收入点连起来，就是一条向右下方倾斜的 IS 曲线。IS 上的每一点都表示"产品市场供求是平衡的"。

记忆法
"Investment = Saving（投资 = 储蓄）" 是 IS 的名字来源；记住因果链：r↑ → I↓ → Y↓ "向右下倾斜、斜率为负"——和微观的需求曲线一个方向，好记
公式
两部门：i = s　→　e − dr = −α + (1−β)Y　→　Y = （α + e）/（1 − β）−［d /（1 − β）］r 三部门（定量税）：Y = （α + e + G − βT + βTR）/（1 − β）−［d /（1 − β）］r 三部门（比例税）：Y = （α + e + G + βTR）/［1 − β(1 − t)］−［d /（1 − β(1 − t)）］r

推导套路（必会）：① 写 AE = C + I（+ G）；② 令 AE = Y；③ 把含 Y 的项移到左边、其余留右边；④ 整理成 Y = 截距 − 斜率×r 的形式。

11-2IS 的斜率与"谁决定陡峭"★★★简答
大白话

IS 的陡缓取决于"利率变动 1 单位能撬动多少收入"：投资对利率越敏感（d 大），或乘数越大（β 大），同样降一点利率就能把收入推得很远 → 曲线越平缓。

记忆法
"敏感就平，迟钝就陡"　→　d 大（投资敏感）、β 大（乘数大）→ IS 平；d 小、β 小 → IS 陡 数学记忆：以 Y 为横轴时，IS 的绝对斜率 = (1−β)/d = 1/(乘数×d)　→　乘数或 d 越大，斜率绝对值越小（越平）
11-3IS 曲线的移动（财政政策）★★★计算
大白话

凡是直接增加总需求的自主支出（G↑、T↓、TR↑、I 自主增加、X↑），都把 IS 往右推；反之往左。

记忆法
"只要是财政扩张，IS 一律右移"；"右移幅度 = 相应乘数 × 政策变化量"

例：ΔG = 100、β = 0.8 → IS 水平右移 5×100 = 500。

公式
IS 水平移动量 ΔYIS = k × Δ（自主支出）　　k 为对应乘数 政府购买：ΔYIS = ΔG /（1 − β）　　税收：ΔYIS = −β·ΔT /（1 − β）
易错

区分"曲线移动"和"点沿线移动"：政府买东西增加 → 整条 IS 右移；利率变化 → 在同一条 IS 上移动。选择题最爱考这个。

11-4货币需求三动机与货币需求函数★★★简答 / 计算
大白话

人们为什么愿意拿着钱？① 交易动机：买东西要花钱（收入越高，要留的钱越多）；② 预防动机：防备意外（也是收入越高越多）；③ 投机动机：等着抄底债券——利率越高，持有货币的机会成本越大，越不愿持币。

记忆法
"交易 + 预防看收入（正），投机看利率（负）"　→　L = kY − hr，一个加一个减 k＝收入敏感度（收入多留钱多），h＝利率敏感度（利率一动就改持币多少）
公式
实际货币需求：L = L1(Y) + L2(r) = kY − h r　　（k > 0，h > 0） 实际货币供给：m = M / P　　（M 名义货币量，P 价格水平） 货币市场均衡：M / P = kY − h r

坑：LM 里的货币供给一定是实际货币供给 M/P，不是名义 M。价格变化会改变实际货币供给——这正是第十二章推导 AD 曲线的钥匙。

11-5LM 曲线的方程与斜率★★★计算
大白话

收入越高 → 交易需要的钱越多 → 在货币总量固定时，只有利率上升才能让人少持投机性的钱、腾出钱来做交易 → 所以收入越高，均衡利率越高，LM 向右上倾斜。

记忆法
"Liquidity preference = Money supply（货币需求 = 货币供给）" 是 LM 名字来源；因果链：Y↑ → 交易需求↑ → r↑ "k 大则陡（钱需求跟着收入猛涨），h 大则平（利率一动大家就调持币）"
公式
由 M/P = kY − hr 得：r = （k / h）Y − m / h　　或　　Y = （h / k）r + m / k

以 Y 为横轴、r 为纵轴时，LM 斜率 = k/h；以 r 为横轴的写法里，斜率 = h/k。答题时先说明横轴是谁，否则容易被扣分。

11-6LM 的三个区域（含流动性陷阱）★★★简答 / 名词解释
大白话

凯恩斯区域（水平段）：利率低到不能再低，大家觉得"债券只会跌"，于是给多少货币都愿意拿着——这就是流动性陷阱（也叫凯恩斯陷阱、流动偏好陷阱）。此时 LM 是水平的。
中间区域：正常向右上倾斜。
古典区域（垂直段）：利率极高，投机需求为零，货币只用于交易，LM 垂直。

记忆法
"低了平（陷阱）、中间斜、高了直（古典）"——从左到右 LM 像一条"躺平 → 爬坡 → 立正"的曲线 参数对应：水平 ⇔ h → ∞（利率稍动，持币意愿无限变）；垂直 ⇔ h = 0（完全不看利率）
易错

流动性陷阱下：货币政策完全失效（印再多钱也被人攥在手里，利率降不下去、投资不增加，像"用绳子推东西"），而财政政策完全有效（不推高利率，没有挤出）。这是必考的对比结论。

11-7LM 曲线的移动★★★计算
大白话

实际货币供给 m = M/P 增加（央行印钱 M↑，或物价下跌 P↓）→ 同样的收入下钱变多了 → 利率可以更低 → LM 向右下（右）移；反之左移。

记忆法
"M 涨、P 跌 → 实际钱变多 → LM 右移"；口诀"钱多右移"
公式
由 Y = （h/k）r + m/k 可知：Δm = ΔM/P → LM 水平移动量 ΔYLM = Δm / k = ΔM /（kP）
11-8IS—LM 共同均衡的求解★★★计算（必考）
大白话

两个市场要同时摆平：产品市场在 IS 上、货币市场在 LM 上，两条线的交点就是唯一的一组（Y*, r*）。

记忆法
解题四步（写下来照做）：① 求 IS → ② 求 LM → ③ 联立消 r → ④ 代回求另一个 + 验算
公式
IS：Y = A − s·r　　（A 为截距，s 为利率项系数） LM：Y = B + f·r　　（B 为截距，f 为利率项系数） 联立：A − s·r = B + f·r　→　r* = （A − B）/（s + f） 　　　Y* = A − s·r*　（再代回 LM 验算一遍）

万能结论（背下来可秒答小题）：
ΔY = ΔA × f/(s+f)（IS 右移 ΔA 时）
ΔY = ΔB × s/(s+f)（LM 右移 ΔB 时）
Δr = ΔA/(s+f)（IS 右移）　或　Δr = −ΔB/(s+f)（LM 右移）

11-9失衡区域的判断（四个象限）★★简答 / 图形
大白话

IS 右边：收入太高，产品供过于求（产品市场超额供给）；IS 左边：需求过旺。
LM 右边：收入高→交易需求大→货币需求 > 货币供给；LM 左边：货币供给过剩（人们想把多余货币换成债券，压低利率）。

记忆法
"IS 之右：东西卖不掉（供>求）；LM 之右：钱不够用（需>供）"

调整方向：不在均衡点时，收入与利率会朝交点方向移动（供过于求→减产；货币供不应求→利率上升）。

11-10挤出效应与财政政策效果★★★论述 / 计算
大白话

政府多花钱 → 收入上升 → 交易需要的钱变多 → 利率被推高 → 企业借钱贵了、少投资，于是政府刺激的效果被"挤掉"一部分。这个被挤掉的部分叫挤出效应。

记忆法
链条背下来：G↑ → Y↑ → 交易货币需求↑ → r↑ → I↓ "财政怕 LM 陡"：LM 越陡（h 小）→ 利率升得多 → 挤出多 → 财政效果小；LM 水平（陷阱）→ 不升息、无挤出 → 财政效果最大 "d 大也挤出多"：投资对利率越敏感，同样的利率上升会砍掉更多投资
公式
理论最大效果（利率不变）：ΔY理论 = kg × ΔG 实际效果（利率可变）：ΔY实际 = kg × ΔG − kg × （d × Δr） 挤出量 = 理论效果 − 实际效果 = 乘数 × 投资减少量

算挤出量的两步：① 用两个均衡点算出 Δr；② 投资减少 ΔI = −d × Δr；③ 挤出 = 乘数 × |ΔI|。

11-11货币政策效果与两种极端★★★论述
大白话

央行印钱 → LM 右移 → 利率下降 → 投资上升 → 收入上升。IS 越陡（投资对利率不敏感 d 小），同样降息撬动的投资越少 → 货币效果越小；极端情况（IS 垂直或 LM 水平）货币政策完全失效。

记忆法
链条：M↑ → r↓ → I↑ → Y↑；"货币怕 IS 平（IS 越平、d 越大，效果反而越大？——注意！这里要分清楚）"

准确表述：LM 越陡（h 小）、IS 越平（d 大）→ 货币政策效果越大。用极端法记忆最快：
· 流动性陷阱（LM 水平）：货币政策无效、财政政策极有效。
· 古典情形（LM 垂直）：财政政策完全挤出、无效、货币政策极有效。

对比表

中间区域右上倾斜有效，但有部分挤出有效

11-12本章评析（IS—LM 的局限）★★论述
大白话

IS—LM 把利率引入了收入决定，但它仍然假设价格水平固定（所以只适用于短期），还把预期、供给方、开放经济都排除在外。

记忆法
三个"没考虑"：没考虑价格变动（→ 引出 AD—AS）、没考虑预期（→ 引出理性预期学派）、没考虑供给

例 1计算（核心题型）求 IS、LM 与共同均衡

某两部门经济：消费 C = 100 + 0.75Y，投资 I = 175 − 5r；货币需求 L = 0.25Y − 15r，名义货币供给 M = 175，价格水平 P = 1。求：（1）IS 曲线方程；（2）LM 曲线方程；（3）产品市场与货币市场同时均衡时的收入与利率；（4）此时的消费、投资与货币需求（验算）。

展开答案与解析

① 求 IS：AE = C + I = 100 + 0.75Y + 175 − 5r = 275 + 0.75Y − 5r；令 AE = Y → 0.25Y = 275 − 5r → Y = 1100 − 20r

② 求 LM：M/P = L → 175 = 0.25Y − 15r → 0.25Y = 175 + 15r → Y = 700 + 60r

③ 联立：1100 − 20r = 700 + 60r → 400 = 80r → r* = 5；Y* = 1100 − 100 = 1000

④ 验算：C = 100 + 750 = 850，I = 175 − 25 = 150，C + I = 1000 = Y ✓；L = 0.25×1000 − 15×5 = 250 − 75 = 175 = M ✓

答案：IS：Y = 1100 − 20r；LM：Y = 700 + 60r；均衡收入 Y* = 1000，均衡利率 r* = 5%。
技巧：这类题的满分习惯是代回验算——把 (Y*, r*) 分别代入 C+I 看是否等于 Y、代入 L 看是否等于 M。两处都对，基本不会错。另外注意这里的 r 用"百分数"作单位（r=5 就是 5%）。
例 2计算财政扩张与挤出效应

承上题。现在政府购买增加 100（其他条件不变）。求：（1）新 IS 曲线；（2）新均衡收入与利率；（3）挤出效应有多大？（4）若利率不变，收入本应增加多少？

展开答案与解析

① 新 IS：0.25Y = 275 + 100 − 5r = 375 − 5r → Y = 1500 − 20r（水平右移 400 = 5×100… 注意：这里乘数 k = 1/(1−0.75) = 4，故右移 4×100 = 400 ✓）

② 联立新 IS 与 LM：1500 − 20r = 700 + 60r → 800 = 80r → r = 10；Y = 1500 − 200 = 1300

③ 投资：原 I = 175 − 5×5 = 150；新 I = 175 − 5×10 = 125 → 投资减少 25

④ 挤出量 = 乘数 × 投资减少量 = 4 × 25 = 100

检验：理论最大 ΔY = 4 × 100 = 400；实际 ΔY = 1300 − 1000 = 300；差额 400 − 300 = 100 ✓ 与挤出量一致

答案：（1）Y = 1500 − 20r；（2）Y = 1300，r = 10%；（3）挤出效应 100；（4）若利率不变，收入应增 400（实际只增 300）。
技巧：挤出效应 = 乘数 × d × Δr = 4 × 5 × 5 = 100。公式记牢：挤出 = k·d·Δr。也记住定性结论：LM 越陡、IS 中 d 越大 → 挤出越大 → 财政效果越小。
例 3计算货币政策效果

承例 1（未加政府购买）。中央银行把名义货币供给从 175 增加到 225。求新均衡收入与利率，并说明货币政策传导链条。

展开答案与解析

新 LM：0.25Y − 15r = 225 → 0.25Y = 225 + 15r → Y = 900 + 60r

联立 IS（Y = 1100 − 20r）：1100 − 20r = 900 + 60r → 200 = 80r → r = 2.5；Y = 1100 − 50 = 1050

对比原均衡：Y 从 1000 → 1050（+50），r 从 5% → 2.5%（下降 2.5 个百分点）

答案：新均衡 Y = 1050，r = 2.5%。传导链条：M↑ → 实际货币供给↑ → LM 右移 → r↓ → I↑（投资从 150 增至 162.5）→ Y↑。
技巧：货币政策题的关键是先判断 LM 移动量：ΔYLM = ΔM/(kP) = 50/(0.25×1) = 200。再用"万能结论"ΔY = ΔB × s/(s+f) = 200 × 20/(20+60) = 50 直接得答案，不用重新解方程。
例 4简答流动性陷阱下为什么货币失灵、财政灵验

什么是流动性陷阱？在流动性陷阱中，为什么货币政策无效而财政政策完全有效？

展开答案与解析

定义：利率极低时，人们预期利率只会上升（债券价格只会下跌），因此无论增加多少货币供给都会被人们以现金形式持有，投机性货币需求变得无限大（h → ∞），LM 呈水平状。

货币无效：增发货币无法使利率进一步下降 → 投资不增加 → 收入不变（形象说法："货币政策像一根绳子，只能拉不能推"）。

财政完全有效：政府支出增加使 IS 右移，由于 LM 水平，收入上升不会推高利率 → 投资不被挤出 → 财政乘数的作用完全发挥。

答案要点：① 定义（利率极低、投机需求无限大、LM 水平）；② 货币政策的传导链条在"r↓"这一环断裂，故无效；③ 财政政策不引起利率上升，挤出效应为零，故完全有效；④ 政策含义：危机中若陷入流动性陷阱，应主要依靠财政政策与非常规货币工具（量化宽松、预期管理）配合。
例 5计算曲线移动量的计算

已知 β = 0.75，政府购买乘数 k = 4，货币需求函数 L = 0.25Y − 15r，P = 1。（1）政府购买增加 60，IS 曲线水平移动多少？（2）货币供给增加 40，LM 曲线水平移动多少？（3）政府税收减少 80（定量税），IS 移动多少、方向如何？

展开答案与解析

（1）ΔYIS = kg × ΔG = 4 × 60 = 240（右移）

（2）ΔYLM = ΔM /（k货币需求 × P）= 40 /（0.25 × 1） = 160（右移）

（3）ΔYIS = kt × ΔT = [−β/(1−β)] × (−80) = (−3) × (−80) = +240（右移）

答案：（1）右移 240；（2）右移 160；（3）右移 240。
技巧：税收的"减税"是 ΔT < 0，乘数是负的，负 × 负 = 正，所以减税使 IS 右移。记不住就记结果：凡是扩张性的，一律右移。
例 6论述财政政策效果的影响因素

用 IS—LM 模型分析：扩张性财政政策的效果受哪些因素影响？什么情况下会出现"完全挤出"？

展开答案与解析

传导：G↑ → IS 右移 → Y↑ 且 r↑ → r↑ 抑制私人投资（挤出）→ 削弱政策效果。

影响因素一：LM 斜率（h）。LM 越陡（h 小，货币需求对利率不敏感），收入上升带来的交易需求必须靠大幅升息来平衡，挤出越大，财政效果越小。

影响因素二：投资利率敏感度 d。d 越大，同样的利率升幅会砍掉更多投资，挤出越大，且 IS 越平缓。

影响因素三：乘数（β）。β 大则乘数大，IS 移动幅度大，但同时也放大挤出的传递。

答案要点：① 效果大小取决于挤出效应；② LM 越陡、d 越大 → 挤出越大 → 效果越小；③ 完全挤出出现在古典情形（LM 垂直）：收入上升完全被利率上升抵消，私人投资下降量恰好等于政府支出增加量，收入不变，只留下利率上升与物价上涨的压力；④ 零挤出出现在流动性陷阱（LM 水平）。

12-1AD 曲线的含义与向右下方倾斜的三个效应★★★简答 / 论述
大白话

总需求曲线说的是"物价水平与社会愿意购买的总量之间的关系"，物价越贵，大家买得越少，所以向右下方倾斜。原因有三条：
① 利率效应：价涨 → 手里的钱不值钱（实际货币供给减少）→ 利率上升 → 投资减少；
② 实际余额效应（财富效应）：价涨 → 居民实际财富缩水 → 消费减少；
③ 税收效应 / 汇率效应（开放经济）：价涨 → 名义收入上升被推入更高税率档次、且本国货变贵 → 消费与净出口减少。

记忆法
三效应顺口溜："价涨 → 钱紧 → 利率升 → 投资减；价涨 → 钱毛 → 消费减；价涨 → 国货贵 → 出口减" 最核心的一条是 利率效应（它也正是从 IS—LM 推导 AD 的机制）
12-2由 IS—LM 推导 AD 曲线（重点计算）★★★推导 / 计算
大白话

让价格 P 变一变：P 上升 → 实际货币供给 M/P 变小 → LM 左移 → 利率升、收入降。于是"高价格 ↔ 低收入"，把这些点连起来就是 AD。

记忆法
四步法：① 写 IS（不含 P）→ ② 写 LM（含 M/P）→ ③ 从 LM 解出 r 代入 IS → ④ 整理成 Y = f(P) "P 在 LM 里，不在 IS 里"——这是推导的全部秘密

IS：Y = A − s·r LM：kY − h·r = M/P　→　r = （kY − M/P）/ h 代入 IS 得：Y = A − （s/h）（kY − M/P） 　　　　　　→ Y（1 + s·k/h） = A + （s·M/h）/ P 　　　　　　→ AD：Y = A/（1 + sk/h） + ［sM/h］/［（1 + sk/h）·P］

12-3AD 曲线的移动与斜率★★★简答

在同一个价格水平下，任何让总支出增加的东西（G↑、T↓、M↑、I 自主↑、X↑、消费信心↑）都把 AD 往右推。

记忆法
"财政扩张、货币扩张 → AD 一律右移"（紧缩则左移）；"价格变 → 点沿 AD 移动；政策变 → 整条 AD 移动"
斜率
AD 越平坦 ⇔ 货币需求的利率敏感度 h 越大、投资敏感度 d 越大、k 越小 （即：IS—LM 中货币政策传导越顺畅，AD 越平）
12-4AS 曲线的三种形状★★★简答 / 图形
大白话

凯恩斯段（水平）：经济很冷，大量机器和工人闲着，企业可以在不涨价的情况下无限量供货——价格刚性。
常规段（向右上倾斜）：越接近满负荷，想再增产就得涨工资、涨原料价，成本推着价格往上走。
古典段（垂直）：已经满负荷，再多需求也只能涨价，产量一点不增（长期总供给 = 潜在产出）。

记忆法
"冷了平（随叫随到）、中间斜（越干越贵）、满了直（加钱也不干）"——想象工厂从"闲置"到"加班"到"三班倒满负荷" "短期斜、长期直"：短期有价格粘性，长期价格和工资都能充分调整，产出回到潜在产出（长期 AS 垂直）
易错

长期 AS 垂直的位置就是潜在产出（自然率水平的产出），它不受价格影响，只由资本、劳动、技术决定。移动长期 AS 必须靠"提高生产能力"（技术进步、资本积累、制度改革），靠印钱是移不动的。

12-5短期 AS 向右上倾斜的三种解释★★简答
大白话

① 粘性工资：工资合同定死了，物价涨了 → 企业卖得贵、工资没涨 → 实际工资下降 → 多雇人、多生产。
② 粘性价格：菜单成本使部分企业来不及调价，物价总水平上升时它们相对便宜 → 销量大增 → 增产。
③ 错觉理论：企业只看到自己产品价格涨，误以为是"相对价格涨了"（没意识到整体物价都涨），于是扩大生产。

记忆法
"工资没跟上、价格没改价、老板看错了"——三个"信息/调整滞后"造成短期 AS 向上斜

共同本质：名义变量调整有粘性、预期不完全。长期里这些错觉和粘性都会消失，所以长期 AS 垂直。

12-6AS 曲线的移动★★★简答
大白话

凡是改变生产成本或生产能力的因素都移动 AS：成本上升（工资涨、原材料/能源涨价、加税）→ 短期 AS 左移（同样的价格只肯少生产）；技术进步、资本增加、劳动力增加、制度改善 → 长期与短期 AS 右移。

记忆法
"成本涨 → 左移（供给收缩）；能力强 → 右移（供给扩张）"

注意区分"沿 AS 的移动"（价格水平变）和"AS 的移动"（成本、技术变）。考试常给一个事件让你判断移动方向：油价暴涨→左移；全民教育水平提高→右移。

12-7AD—AS 均衡的三种情形★★★简答 / 图形
大白话

AD 移动的效果，取决于它落在 AS 的哪一段：水平段（萧条）→ 只增产不涨价；倾斜段（常态）→ 又增产又涨价；垂直段（满负荷）→ 只涨价不增产（货币中性）。

记忆法
AS 所处区段经济状态AD 右移的结果政策含义
凯恩斯段（水平）严重衰退、大量闲置产量大增，价格不变刺激需求非常划算
中间段（右上）常态产量与价格同涨刺激有代价（通胀）
古典段（垂直）充分就业价格大涨，产量不变刺激只会带来通胀
口诀："冷了增产不涨价，满了涨价不增产，中间两个一起来"
12-8需求冲击的短期与长期调整★★★论述 / 计算
大白话

比如央行多印钱：短期价格还没反应过来（价格粘性），实际货币增多 → 利率降 → 产出上升（超过潜在水平）；但长期价格会涨上来，把实际货币供给"吃回去"，产出回到潜在水平，只剩下价格上升。

记忆法
"短期动产量，长期动价格"；"货币在短期非中性，在长期中性"

自我修正机制：产出高于潜在 → 工资成本上升 → 短期 AS 左移 → 价格继续涨、产出回落，直到回到潜在产出。

计算思路
短期：先按价格粘性令 P = P0 代入 AD 求 Y短 长期：令 Y = 潜在产出 Ȳ 代入 AD，解出新的 P长
12-9供给冲击与滞胀★★★论述
大白话

石油暴涨之类的成本冲击把 AS 往左推：企业成本上升 → 减产 + 涨价 → 于是物价上涨和产出下降、失业上升同时出现，这就是滞胀（停滞 + 通胀）。

记忆法
判别口诀："需求冲击：价量同向；供给冲击：价量反向" 滞胀 = 高通胀 + 高失业（AD—AS 图上：AS 左移，均衡点向左上方移动）
易错

滞胀不能用扩张性需求政策解决：刺激需求虽然能拉回产出，但会让物价更上一层楼；而要压通胀就得紧缩，又会让失业更严重。这是政策两难，正确答案通常是"短期需求管理 + 长期供给端政策（技术进步、降低对能源依赖、提高劳动力流动性）"。

12-10稳定政策的取舍（要不要干预）★★论述
大白话

对需求冲击：政策可以对冲（AD 左移就刺激、右移就紧缩），能同时稳住产出和物价，所以"积极干预"有道理。
对供给冲击：政策无法两全，只能二选一（保就业就接受通胀、压通胀就接受衰退），所以干预效果有限。

记忆法
"需求冲击可对冲，供给冲击只能二选一"；答题加一句"政策存在时滞与不确定性，过猛的干预本身也可能成为波动来源"

已知 IS 曲线为 Y = 900 − 20r，货币需求 L = 0.25Y − 10r，名义货币供给 M = 150，价格水平为 P。求总需求曲线 AD 的方程；当 P = 1 时的收入与利率。

→ 200/P = 200P → P2 = 1 → P = 1；Y = 600 + 200 = 800

此时 Y = 潜在产出 800，价格水平等于预期水平（P = 1）

例 3计算需求冲击：短期效应与长期调整

承上，中央银行把货币供给由 150 增至 225。（1）求新的 AD 曲线；（2）价格粘性在 P = 1 时的短期均衡；（3）长期中产出回到潜在水平 800 时的价格水平与利率。

（1）新 LM：0.25Y − 10r = 225/P → r = 0.025Y − 22.5/P；代入 IS：Y = 900 − 0.5Y + 450/P → 新 AD：Y = 600 + 300/P

13-2失业的影响与奥肯定律★★★计算 / 简答
大白话

失业率每比自然失业率高出 1 个百分点，实际 GDP 就会比潜在 GDP低大约 2%。失业不是"几个人的事"，它是真金白银的产出损失。

记忆法
"1 个失业 → 2 个产出"（超自然失业率 1%，产出缺口 −2%） 公式记忆：（Y − Y*）/ Y* = −α（u − u*），α ≈ 2；注意负号——失业越高，产出越低于潜在
公式
奥肯定律：（Y − Y*）/ Y* = − α（u − u*）　　（α ≈ 2） 等价写法：失业率每上升 1 个百分点，实际 GDP 增长率约下降 2 个百分点（相对潜在增速）

计算三步：① 算失业率缺口 u − u*；② 乘 −α 得产出缺口率；③ 用潜在 GDP 换算出实际 GDP 或产出损失。

易错

奥肯定律是经验规律（教材特别强调：它只是对美国经济现象的总结，没有严格检验，会因时因地而异），答题时要补一句"数量关系不一定准确，只具参考意义"，这是加分点。

13-3通货膨胀的定义与类型★★★名词解释 / 选择
大白话

通货膨胀 = 物价总水平普遍、持续、显著上涨。三个关键词缺一不可：不是个别商品涨（普遍）、不是一次性涨价（持续）、不是微小波动（显著）。

记忆法
按程度分：爬行（温和）→ 奔腾 → 恶性　联想"散步、跑步、狂奔" 按预期分：预期到的 / 未预期到的；按成因分：需求拉动 / 成本推动 / 结构性
13-4通胀的三大成因（必考）★★★简答 / 论述
大白话

① 需求拉动：想买的人太多——"过多的货币追逐过少的商品"（AD 右移）；
② 成本推动：造东西变贵了——工资涨、原材料（石油）涨，企业被迫提价（AS 左移）；
③ 结构性：有的行业涨、有的不涨，但工资互相攀比，成本被抬上去。

记忆法
"需求拉 = 抢的人多；成本推 = 造的贵；结构性 = 攀比跟风" 图形对应（超好用）：需求拉动 → AD 右移（价涨量增）；成本推动 → AS 左移（价涨量减＝滞胀）

货币主义的说法（弗里德曼）："通货膨胀无论何时何地都是一种货币现象"——这句话是名句，论述题可直接引用。

易错

区分"一次性的价格水平上升"和"持续的通货膨胀"：只有货币供给持续扩张才能维持持续通胀（通胀惯性）。这是货币主义的核心观点，常考。

13-5通货膨胀的影响（成本）★★★简答
大白话

预期到的通胀：主要带来"麻烦"——频繁改价签（菜单成本）、少存钱多跑银行（鞋底成本）、税收被通胀推高档次（税收扭曲）、比价混乱。
没预期到的通胀：主要带来"抢劫"——财富在债权人和债务人之间重新分配。

记忆法
"欠钱的笑，存钱的哭"：通胀使债务人受益（还的钱不值钱了）、债权人受损；拿固定工资和养老金的人受损，利润收入者往往受益 预期到的四类成本：菜单成本、鞋底成本、税收扭曲、相对价格混乱　→　"菜单鞋底税收乱"
13-6菲利普斯曲线：从总供给曲线到通胀—失业替代★★★推导 / 简答
大白话

菲利普斯曲线其实就是"换了个马甲的总供给曲线"：产出高 → 失业低 → 工资、物价涨得快 → 通胀高。所以通胀和失业在短期是"跷跷板"，此消彼长。

记忆法
"PC = 另一个版本的 AS 曲线"（教材原话）；"短期负斜率，长期垂直" 推导逻辑：Y 高 → u 低 → P 涨得快 → π 高
公式
短期总供给：Y = Y* + α（P − PE） + v　　教材式（13.6） 菲利普斯曲线：π = πe − ε（u − u*） + v 　　π：实际通胀率　πe：预期通胀率　u*：自然失业率　v：供给冲击

读公式的口诀：失业低于自然率（u < u*）→ 括号为负 → 通胀高于预期；反之亦然。供给冲击 v > 0（如油价暴涨）直接把整条曲线往上抬。

13-7适应性预期与通胀加速★★★计算 / 论述
大白话

适应性预期：人们"看后视镜开车"——用过去的通胀来猜未来的通胀（πe = π−1）。后果：政府若想长期把失业压在自然率以下，就必须让通胀一年比一年高（加速），否则失业就会回到自然率。

记忆法
"适应性预期 = 拿昨天猜明天；理性预期 = 用尽所有信息" "想靠通胀买就业，得年年加码，最后只剩通胀"——这就是"通胀加速"与"自然率假说"
公式
极端适应性预期：πe = π−1　→　π = π−1 − ε（u − u*） + v　教材式（13.12） 结论：维持 u < u* 需 π > π−1（通胀逐年加速）； 　　　若 u = u* 且 v = 0，则 π = π−1（通胀稳定不变，即"惯性通胀"）
13-8长期菲利普斯曲线与自然率假说★★★论述
大白话

短期可以用通胀"骗"来一点就业，但工人迟早发现"物价涨了、实际工资没涨"，就会要求加工资、减少劳动供给 → 失业回到自然率，只剩下更高的通胀。把各期的结果连起来，就是一条垂直于自然失业率的长期菲利普斯曲线。

记忆法
"短期有替代，长期没替代；骗得了一次，骗不了一世" 短期 PC 移动规律：πe 上升 → 整条短期 PC 向上平移（预期通胀是多少，PC 就从那个高度出发）
易错

长期 PC 垂直的位置是 u*（自然失业率），而 u* 本身不是常数——它受劳动力结构、制度、技术影响会变（教材特别强调"不是一个固定不变的量"）。

13-9理性预期与政策无效性命题★★★论述
大白话

理性预期：人们会利用所有可得信息（包括"政府要干什么"）来形成预期，不会系统性犯错。于是：被公众预料到的货币扩张，只会立刻反映为物价和预期上涨，失业一点不降；只有没预料到的政策才在短期有效。

记忆法
"预料到的政策只改价格，不改产出；只有意外的政策才短期有效"（新古典宏观的政策无效性命题） 三人对比：凯恩斯（短期有效、工资粘性）→ 弗里德曼（适应性预期、短期有效长期无效）→ 卢卡斯（理性预期、连短期也基本无效）
13-10降低通胀的代价：牺牲率★★名词解释 / 计算
大白话

通胀有惯性，要把它压下来，必须经历一段产出低于潜在水平、失业高于自然率的痛苦时期。牺牲率 = 通胀率每下降 1 个百分点，要损失多少个百分点的 GDP。

记忆法
"治通胀要付学费，学费就是产出损失"；典型数值：牺牲率约 5（通胀降 1%，GDP 损失约 5%）
公式
牺牲率 = GDP 的累计损失百分比 ÷ 通货膨胀率的下降幅度
易错

若公众信任政府的反通胀承诺（可信性），预期会迅速下调，牺牲率会小很多（无痛反通胀）——这是"预期管理"的理论依据，答论述题非常好用。

13-11通货紧缩与滞胀★★★简答
大白话

通货紧缩：物价持续普遍下跌。听起来是好事，实际很糟——大家捂着钱等更便宜（推迟消费）、债务实际负担变重（欠的钱更"值钱"）、实际利率上升，形成"越等越跌"的恶性循环。
滞胀：高通胀 + 高失业并存，源于不利供给冲击。

记忆法
通缩三害：推迟消费、债务变重、实际利率上升　→　"不买、还不起、借不到" 滞胀判别：价涨 + 量减 + 失业升 = AS 左移
13-12经济周期：定义、阶段与类型★★★简答 / 选择
大白话

经济周期 = 总体经济活动的扩张与收缩交替。四阶段：繁荣 → 衰退 → 萧条 → 复苏，两个转折点是顶峰和谷底。

记忆法
四类周期按长度（由短到长）：基钦（存货，3—5 年）、朱格拉（设备投资，8—10 年）、库兹涅茨（建筑，15—25 年）、康德拉季耶夫（技术革命，50—60 年） 口诀："基（存货）朱（设备）库（建筑）康（技术）"　→　联想"记住库房"：记(基)住(朱)库(库)房→康
易错

经济周期不是固定长度的机械循环，而是"扩张与收缩交替、持续时间不等"的波动；现代宏观不再追求"精准预测周期"，而是研究冲击 + 传导机制。

13-13经济周期理论：从外生到现代★★简答
大白话

早期理论喜欢找"外部原因"（太阳黑子、心理、货币、创新）；现代理论把周期看成"冲击 + 传导"：
· 实际经济周期（RBC）：技术冲击是主因，市场能自我调节，周期是"最优反应"；
· 货币主义：货币供给的不当变动是主因；
· 新凯恩斯主义：名义粘性（价格、工资调不动）使需求冲击被放大成产出波动，所以需要政策干预。

记忆法
一图记三派：RBC＝技术冲击＋不用管；货币主义＝货币乱＋按规则办；新凯恩斯＝粘性＋该出手就出手
易错

教材"本章评析"强调：西方周期理论回避了资本主义基本矛盾，对危机的根源解释有局限；分析中国经济要立足社会主义初级阶段的基本国情与结构性因素。这类"评析"题按教材口吻作答即可。

第十三章 例题

6 道
例 1计算奥肯定律

某国自然失业率为 5%，当前实际失业率为 7%，潜在 GDP 为 10000 亿元。按奥肯定律（α = 2）计算：（1）产出缺口率；（2）实际 GDP；（3）产出损失；（4）若该国希望把失业率降到 6%，实际 GDP 应为多少？

展开答案与解析

（1）u − u* = 7% − 5% = 2 个百分点 → 产出缺口率 = −2 × 2% = −4%

（2）实际 GDP = 10000 × (1 − 4%) = 9600 亿元

（3）产出损失 = 10000 − 9600 = 400 亿元

（4）u = 6% → 缺口率 = −2 × 1% = −2% → 实际 GDP = 10000 × 98% = 9800 亿元（比现在多 200 亿元）

答案：（1）−4%；（2）9600 亿元；（3）400 亿元；（4）9800 亿元。
技巧：奥肯定律就是一道"乘 2 换号"的题：失业率超几个点 → 产出缺口就是负的几乘 2 个点。写答案时一定带上负号（产出低于潜在）。
例 2计算菲利普斯曲线与通胀加速

设短期菲利普斯曲线为 π = πe − 0.5（u − u*），自然失业率 u* = 5%，初始时经济处于长期均衡、通胀率为 2%。（1）第 1 年政府把失业率压到 4%，通胀率是多少？（2）若人们按"上一期通胀"形成预期（极端适应性预期），政府第 2、3 年继续把失业率维持在 4%，通胀率分别是多少？（3）长期结果如何？

展开答案与解析

（1）第 1 年：πe = 2% → π = 2% − 0.5×(4% − 5%) = 2% + 0.5% = 2.5%

（2）第 2 年 πe = π−1 = 2.5% → π = 2.5% + 0.5% = 3.0%；第 3 年 πe = 3.0% → π = 3.5%

（3）长期：预期不断上移，短期 PC 逐年向上平移，失业率最终仍回到 u* = 5%，而通胀率却停留在更高水平（若继续强压就需年年加速）

答案：（1）2.5%；（2）3.0%、3.5%；（3）长期失业回到 5%，只留下更高的通胀——长期菲利普斯曲线垂直。
技巧：这类题是"递推"：每一期的 π 自动成为下一期的 πe，只要 u < u* 就每期加 ε×(u*−u)。看到"维持失业率低于自然率"就写"通胀加速"，看到"长期"就写"回到自然率"。
例 3计算实际利率、通胀与再分配

某储户年初存入 10000 元，名义年利率 5%，当年 CPI 上涨 3%。（1）按费雪方程估算实际利率；（2）一年后本息共多少？按年初物价折算的实际购买力是多少？（3）说明通胀对债权人、债务人、固定收入者的影响。

展开答案与解析

（1）实际利率 ≈ 名义利率 − 通胀率 = 5% − 3% = 2%（精确式：(1.05/1.03) − 1 ≈ 1.94%）

（2）名义本息 = 10000 × 1.05 = 10500 元；按年初物价折算 = 10500 ÷ 1.03 ≈ 10194 元（实际只多买了 194 元的东西）

（3）通胀使债权人（储户）受损、债务人受益（还的钱不值钱）；拿固定名义工资/养老金的人实际收入下降；而能随通胀调整价格的企业与利润收入者相对受益。

答案：（1）约 2%；（2）名义 10500 元，实际购买力约 10194 元；（3）财富从债权人向债务人、从固定收入者向灵活定价者转移。
技巧：费雪方程近似式 r ≈ i − π 一定要会（精确式 (1+i)/(1+π) − 1）。判断"谁吃亏"的万能句：凡是名义金额固定的（债权、固定工资），通胀一来就吃亏。
例 4选择 / 简答三种通胀成因的判别

判断下列情形属于哪种通货膨胀，并说明在 AD—AS 图形上如何表现：（1）政府大规模减税、央行降准降息，消费投资两旺，物价上涨；（2）OPEC 再次把油价提高一倍；（3）新兴产业工资大涨，传统产业工人以"攀比"为由要求同等涨幅，全社会工资成本上升。

展开答案与解析

（1）需求拉动型：政策扩张 → AD 右移 → 价格上升、产出增加（短期）。

（2）成本推动型：原材料涨价 → 短期 AS 左移 → 价格上升、产出下降（滞胀倾向）。

（3）结构性通货膨胀：部门间生产率与工资攀比 → 成本普遍抬升，本质也是供给侧的 AS 左移。

答案：（1）需求拉动（AD 右移）；（2）成本推动（AS 左移）；（3）结构性（成本推动的一种，AS 左移）。
秒杀技巧：题干里出现"货币、信贷、减税、消费投资两旺"→ 需求拉动；出现"工资、石油、原材料、汇率导致进口成本"→ 成本推动；出现"部门差异、攀比"→ 结构性。
例 5论述短期与长期菲利普斯曲线

试述菲利普斯曲线的演变：从原始菲利普斯曲线到附加预期的菲利普斯曲线，再到长期垂直的菲利普斯曲线，并说明其政策含义。

展开答案与解析

① 原始 PC（菲利普斯）：失业率与货币工资增长率负相关 → 后来改写成失业率与通货膨胀率负相关，提供"通胀换就业"的政策菜单。

② 附加预期的 PC（弗里德曼、费尔普斯）：π = πe − ε(u − u*) + v。决定通胀的不是失业率本身，而是失业率相对自然失业率的偏离；预期通胀上升会使整条短期 PC 上移。

③ 长期 PC：预期可充分调整（π = πe）→ 必有 u = u*，长期 PC 是过自然失业率的垂线，通胀与失业无替代关系。

答案要点：政策含义有三层——短期存在替代，需求管理可以调节失业；长期不存在替代，扩张只会留下通胀；因此不能靠通胀买就业，降低失业的根本办法是改善劳动市场运行（培训、就业服务、消除工资刚性），把自然失业率本身降下来。
例 6简答经济周期的阶段与类型

什么是经济周期？它分为哪几个阶段？按长度可分为哪几种类型？各由什么因素主导？

展开答案与解析

定义：总体经济活动的扩张与收缩交替出现的现象（通常以实际 GDP 的波动来衡量）。

四阶段：繁荣（顶峰）→ 衰退 → 萧条（谷底）→ 复苏；两个转折点：峰与谷。

四类型：基钦周期（3—5 年，存货投资）、朱格拉周期（8—10 年，设备投资）、库兹涅茨周期（15—25 年，建筑业）、康德拉季耶夫周期（50—60 年，技术革命）。

答案要点。补充得分点：① 现代观点把周期看作"冲击 + 传导机制"的结果；② 需求冲击（货币、财政、信心）与供给冲击（技术、能源）都能引发波动；③ 由于价格粘性，需求冲击在短期会造成产出与就业的真实波动，这是新凯恩斯主义主张适度干预的依据。
记忆："基朱库康"对应"存货—设备—建筑—技术"，长度从短到长，选择题常直接考对应关系。

14-1国际收支与国际收支平衡表★★★选择 / 简答
大白话

国际收支平衡表就是一国对外经济往来的"记账本"，记两件大事：买卖东西和服务（经常账户）和买卖资产、借钱（资本和金融账户），外加官方储备变动和"记不平的差额"（净误差与遗漏）。

记忆法
经常账户四件套：货物（商品）、服务、收益（工资与投资收益）、经常转移（侨汇、援助）　→　"货服收转" 金融账户：直接投资、证券投资、其他投资、储备资产；储备资产是央行的"外汇家底"，是平衡项 记账口诀（最容易忘）：出口（卖东西给外国人）、收到外国人的钱 → 记贷方（+）；进口、钱流向国外 → 记借方（−）
公式
经常账户差额 + 资本和金融账户差额（不含储备） + 储备资产变动 + 净误差与遗漏 = 0

推论：经常账户顺差（净出口为正）时，必然对应资本净流出或储备增加——"赚了外国人的钱，要么去买外国资产，要么变成外汇储备"。

14-2汇率、标价法与汇率制度★★★名词解释 / 计算
大白话

名义汇率：两种货币的兑换比价。实际汇率：扣掉两国物价后，本国货相对外国货到底贵不贵——它才真正决定净出口。

记忆法
标价法判别（超重要）：直接标价法（1 单位外币 = ? 本币，中国常用，如 1 美元 = 7 元）→ 数字上升 = 本币贬值；间接标价法（1 单位本币 = ? 外币）→ 数字上升 = 本币升值 "本币贬值 → 国货变便宜 → 净出口增加"；"本币升值 → 国货变贵 → 净出口减少"（先把这句话记死，公式就不会搞反）
公式
实际汇率（本币用间接标价 e 时）：ε = e × P / Pf 　　ε 上升 = 本国货相对更贵 = 净出口 NX 减少 净出口函数：NX = NX（ε），是实际汇率的减函数

汇率制度三分：固定汇率制（央行有义务干预维持）、浮动汇率制（自由波动）、管理浮动（有管理的浮动）。

易错

教材（蒙代尔—弗莱明部分）用"e 上升 = 本币升值"的写法（e 为间接标价，汇率在纵轴），与国内新闻常用的"人民币兑美元 7.2"方向相反。答题时先声明标价法，或直接说"升值/贬值"而不用"上升/下降"，最保险。

14-3净出口函数、资本净流出与国际收支平衡（BP）★★★简答 / 计算
大白话

净出口 NX：本国收入越高 → 买外国货越多 → 净出口越少；本币升值 → 净出口越少。
资本净流出 F：本国利率越高 → 钱更愿意留在本国（还能吸引外资流入）→ 资本净流出越少。
国际收支平衡：卖东西净赚的外汇（NX）＝流向国外的净资本（F）。

记忆法
"NX 怕收入高、怕升值；F 怕利率高"　→　NX = NX(ε, Y) 递减；F = F(r) 递减 BP 曲线倾斜方向：Y↑ → 进口↑ → NX↓ → 必须靠 r↑（吸钱进来）来补 → BP 向右上方倾斜
公式
国际收支平衡：NX = F　　即　NX（Y, ε）= F（r） BP 曲线上方（利率偏高）→ F 偏小 → NX > F → 国际收支顺差 BP 曲线下方（利率偏低）→ F 偏大 → NX < F → 国际收支逆差
易错

资本完全流动时，BP 是一条水平线（本国利率必须等于世界利率 rw，稍高就有无限资本流入）；资本完全不流动时，BP 垂直。这是分析蒙代尔—弗莱明的前提。

14-4蒙代尔—弗莱明模型的基本框架★★★简答
大白话

研究一个"小国"（不能影响世界利率）在资本完全自由流动下的宏观政策：本国利率被世界利率 rw 钉住，剩下的变量是收入 Y 和汇率 e。

记忆法
两条曲线：IS*（产品市场：Y = C + I(rw) + G + NX(e)），LM*（货币市场：M/P = L(rw, Y)） 关键：LM* 与汇率无关，所以 LM* 是垂直线，它单独决定 Y；IS* 决定汇率 e
公式
IS*：Y = C（Y − T） + I（rw） + G + NX（e） LM*：M / P = L（rw, Y）　→　给定 M、P 就直接决定 Y
14-5浮动汇率制下的财政政策（无效）★★★论述
大白话

政府多花钱 → 收入想上升 → 利率想上升 → 外国人闻着高利率把钱涌进来 → 抢着买本币 → 本币升值 → 本国货变贵 → 出口锐减、进口大增 → 净出口的减少刚好抵消了政府支出的增加 → 收入一点没变。

记忆法
链条：G↑ → IS*右移 → e↑（升值）→ NX↓ → Y 不变 "挤出的不是投资，而是净出口"——这是蒙代尔—弗莱明里最独特的一句话，论述题写出来很加分
14-6浮动汇率制下的货币政策（有效）★★★论述
大白话

央行印钱 → 利率想下降 → 资本外流 → 本币贬值 → 本国货变便宜 → 出口大增、进口减少 → 净出口增加 → 收入上升。汇率这个"额外通道"让货币政策威力大增。

记忆法
链条：M↑ → LM*右移 → e↓（贬值）→ NX↑ → Y↑ "浮动汇率下，货币政策多了一条'汇率'腿，所以特别灵"
14-7固定汇率制下的财政政策（有效）★★★论述
大白话

政府多花钱 → 利率想上升 → 外资涌入、本币有升值压力 → 央行为守住汇率，必须买外汇、投放本币 → 货币供给被动增加 → LM* 右移 → 收入大幅增加。央行等于"被迫配合"了财政扩张。

记忆法
链条：G↑ → IS*右移 → 升值压力 → 央行买入外汇、投放本币 → M↑ → LM*右移 → Y↑↑ "固定汇率下，央行被汇率绑住，货币政策只能'配合'财政"
14-8固定汇率制下的货币政策（无效）★★★论述
大白话

央行想多印钱 → 利率下降 → 资本外流、本币有贬值压力 → 央行为守住汇率必须抛外汇、收回本币 → 刚放出去的钱又被收回来 → 货币供给回到原样 → 收入不变。货币政策在固定汇率下"自废武功"。

记忆法
链条：M↑ → LM*右移 → 贬值压力 → 央行抛外汇、收回本币 → M 回落 → 无效 "固定汇率 + 资本自由流动 = 货币当局丧失货币主权"
14-9四格总表（本章最核心的结论）★★★必背
大白话

把上面的四条结论压成一张表，考前背这一张就够。

记忆法
资本完全流动的小型开放经济财政政策货币政策贸易政策（关税/配额）
浮动汇率制无效（汇率升值挤出净出口）有效（贬值刺激净出口）无效，贸易量减少
固定汇率制有效（央行被动扩表配合）无效（货币供给被外汇干预抵消）有效（收入增加）
口诀（务必背熟）："固定汇率——财政灵、货币废；浮动汇率——货币灵、财政废"　→　缩记为 "固财浮货"

为什么固定汇率下财政灵？因为央行为了守汇率被迫放水，等于财政、货币一起发力。为什么浮动汇率下货币灵？因为汇率贬值给了货币政策一条额外的传导渠道。

14-10贸易政策的效果★★简答
大白话

浮动汇率下加关税：进口被限制 → 净出口想增加 → 本币升值 → 出口被升值打回去 → 净出口回到原点、收入不变，只是贸易量变小了（白白损失效率）。
固定汇率下加关税：汇率不动 → 净出口真的增加 → 收入上升。

记忆法
"浮动汇率会'自动抵消'贸易保护，固定汇率不会"；结论：以贸易保护来增加就业，在浮动汇率下无效
14-11三元悖论（不可能的三位一体）★★★论述 / 简答
大白话

三样好东西：① 资本自由流动、② 汇率固定、③ 货币政策独立——最多只能同时拥有两个，第三个必须放弃。

记忆法
"自由的钱、钉住的汇率、自己的利率——三选二"

典型组合：
· 美国：资本自由流动 + 浮动汇率 + 货币政策独立（放弃固定汇率）
· 中国香港：资本自由流动 + 固定汇率（联系汇率） + 放弃货币政策独立
· 中国内地：汇率有管理 + 货币政策保持独立 + 资本账户部分管理

14-12价格变动的蒙代尔—弗莱明与 J 曲线效应★★简答
大白话

价格可变时：短期价格粘性，政策能影响产出；长期价格调整后，产出回到自然率水平，只留下价格与汇率的变化（开放经济版的"长期中性"）。
J 曲线效应：本币贬值后，贸易收支会先恶化、后改善，形状像字母 J（因为合同已签、数量调整需要时间）。

记忆法
J 曲线三阶段：货币合同阶段（价格数量都不变）→ 传导阶段（价格变、数量没变，继续恶化）→ 数量调整阶段（数量大变，转为改善）

例 1计算国际收支平衡表记账

某国一年内发生如下对外交易（单位：亿美元）：① 出口服装 100；② 进口设备 80；③ 外商来华直接投资 50；④ 本国企业购买外国债券 30；⑤ 收到海外侨汇 10。请说明每笔交易记入哪个账户的借方还是贷方，计算经常账户差额、资本和金融账户（不含储备）差额，以及储备资产变动。

展开答案与解析

① 出口服装 100 → 经常账户（货物）贷方 +100；② 进口设备 80 → 经常账户（货物）借方 −80

③ 外商直接投资 50 → 金融账户贷方 +50（外资流入＝本国资产被买走，记贷方）；④ 购买外国债券 30 → 金融账户借方 −30（资本流出）

⑤ 侨汇 10 → 经常账户（经常转移）贷方 +10

经常账户差额 = 100 − 80 + 10 = +30（顺差）；金融账户（不含储备）= 50 − 30 = +20

由恒等式：30 + 20 + 储备变动 = 0 → 储备资产变动 = −50（即储备增加 50 亿美元）

答案：经常账户顺差 30 亿；金融账户（不含储备）净流入 20 亿；储备资产增加 50 亿。
技巧：记账只需判断"钱进来了还是出去了"：钱进来记贷方（+），钱出去记借方（−）。储备资产是平衡项，用恒等式倒推即可。
例 2计算名义汇率与实际汇率

采用间接标价法（1 单位本币折合外币），初始汇率 e = 0.14（美元/本币），本国价格水平 P = 100，外国价格水平 Pf = 20（美元）。（1）求初始实际汇率；（2）若本币升值至 e = 0.16，实际汇率变为多少？对净出口有何影响？（3）若本国发生通胀使 P 上升到 110（汇率不变），实际汇率与净出口如何变化？

展开答案与解析

（1）ε = e × P / Pf = 0.14 × 100 / 20 = 0.70

（2）e = 0.16 → ε = 0.16 × 100 / 20 = 0.80 → 本国货相对外国货变贵 → 净出口减少

（3）P = 110 → ε = 0.14 × 110 / 20 = 0.77 → 同样变贵 → 净出口减少

答案：（1）0.70；（2）0.80，净出口减少；（3）0.77，净出口减少。
技巧：实际汇率只要记住一句话——"ε 越大，本国货越贵，越卖不出去（NX 越小）"。本币升值、本国通胀，都会让 ε 变大。答题时如果怕标价法搞混，就只说"升值/贬值"并给出结论，老师一般不会扣你方向分。
例 3计算 + 判断BP 曲线与顺逆差

某国净出口 NX = 400 − 0.1Y，资本净流出 F = 500 − 25r（Y 为收入，r 为利率，% ）。（1）求国际收支平衡（BP）曲线方程；（2）当 Y = 1000、r = 5 时，该国国际收支是顺差还是逆差？（3）当 Y = 1000、r = 10 时又如何？

展开答案与解析

（1）BP：NX = F → 400 − 0.1Y = 500 − 25r → 0.1Y = 25r − 100 → Y = 250r − 1000（向右上方倾斜）

（2）Y = 1000、r = 5：NX = 400 − 100 = 300；F = 500 − 125 = 375 → NX < F → 逆差（资本流出大于贸易顺差，外汇供不应求）

（3）Y = 1000、r = 10：NX = 300；F = 500 − 250 = 250 → NX > F → 顺差

答案：（1）Y = 250r − 1000；（2）逆差；（3）顺差。
技巧：不用公式也能秒判——BP 曲线"上方"（利率偏高）＝顺差，"下方"（利率偏低）＝逆差。原因：利率高 → 钱愿意留下来（资本净流出少）→ 外汇来源够覆盖贸易缺口。
例 4论述（必考）蒙代尔—弗莱明模型下的政策效果

在资本完全流动的小型开放经济中，比较固定汇率制与浮动汇率制下财政政策和货币政策的效果，并说明原因。

展开答案与解析

前提：本国利率被世界利率 rw 钉住，IS* 决定汇率、LM* 决定收入。

浮动 + 财政（无效）：G↑ → IS* 右移 → 利率有上升压力 → 资本流入 → 本币升值 → NX 减少，恰好抵消政府支出增加 → Y 不变。

浮动 + 货币（有效）：M↑ → LM* 右移 → 利率有下降压力 → 资本外流 → 本币贬值 → NX 增加 → Y 上升。

固定 + 财政（有效）：G↑ → IS* 右移 → 本币有升值压力 → 央行买入外汇、投放本币 → M↑ → LM* 右移 → Y 上升。

固定 + 货币（无效）：M↑ → LM* 右移 → 本币有贬值压力 → 央行抛售外汇、收回本币 → M 回到原水平 → Y 不变。

答案核心（一句话）：固定汇率制下财政政策有效、货币政策无效；浮动汇率制下货币政策有效、财政政策无效（"固财浮货"）。根本原因在于：固定汇率制下央行必须动用货币供给来维持汇率，因而丧失了货币政策的独立性；而浮动汇率制下汇率成为吸收外部冲击、放大货币政策效果的渠道，同时也会"挤出"财政政策的净出口。
答题模板：① 先写前提（小型开放经济 + 资本完全流动 + r = rw）；② 四条结论各写一条传导链（一定要出现"升值/贬值"和"净出口"）；③ 最后用"固财浮货"收尾并点出央行干预机制。
例 5简答三元悖论的应用

什么是"不可能的三位一体（三元悖论）"？结合现实举例说明三个目标为何不能同时实现。

展开答案与解析

含义：一国无法同时实现资本自由流动、汇率稳定（固定汇率）、货币政策独立性三个目标，最多只能取其二。

逻辑：资本自由流动时，本国利率偏离世界利率就会引发无限规模的资本流动；若又要固定汇率，央行就必须被动买卖外汇、吞吐本币，货币供给被"外部绑架"，货币政策独立性随之丧失。

答案要点＋例子：① 实行资本管制的国家，可以同时拥有固定汇率与独立的货币政策；② 中国香港的货币局制度：资本自由流动 + 联系汇率，利率只能跟随美元，放弃货币政策独立；③ 大型经济体（如美国）选择浮动汇率，保住了货币政策独立性；④ 现实中更多是"中间解"：有管理的浮动 + 部分资本账户管理 + 一定程度的政策自主，需要在三者之间动态权衡。

第十一章 IS—LM

公式用途 / 记忆
IS：Y = (α + e + G − βT + βTR)/(1−β) − [d/(1−β)]r产品市场均衡，右下方倾斜

第十二章 AD—AS

公式用途 / 记忆
推导 AD：由 LM 解出 r = (kY − M/P)/h，代入 IS结果形如 Y = 常数 + 常数/P

短期均衡：令 P = P0（粘性）代入 AD 求 Y短期动产量

附录三五大计算题型标准套路

看到题目先"对题型"，再按套路走，计算题基本不会丢分。

题型一：乘数类（第十章）

  • 先找 β（题里给消费函数就直接读；给表格就 ΔC/ΔY）。
  • 判断"谁在动"：政府买 → 1/(1−β)；税收 → −β/(1−β)；转移支付 → β/(1−β)；同时动 → 分别算再相加。
  • 比例税 → 分母换成 1−β(1−t)；四部门 → 分母 1−β+γ。
  • 验算：把结果代回 AE = Y。

题型二：IS—LM 联立（第十一章）

  • ① 由 Y = C+I(+G) 令 AE = Y → 得 IS：Y = A − s·r。
  • ② 由 M/P = kY − hr → 得 LM：Y = B + f·r。
  • ③ r* = (A−B)/(s+f)，回代得 Y*。
  • ④ 挤出 = 乘数 × d × Δr；ΔY 也等于 ΔA × f/(s+f)。

题型三：AD—AS（第十二章）

  • 推 AD：从 LM 解 r，代入 IS，整理成 Y = 常数 + 常数/P。
  • 短期：价格粘性 → 令 P = P0 代 AD 求 Y。
  • 长期：令 Y = Y*（潜在产出）代 AD 反解 P。
  • 冲击判别：AD 移→价量同向；AS 移→价量反向。

题型四：奥肯 + 菲利普斯（第十三章）

  • 奥肯：缺口 = (u−u*) × 2，加负号就是产出缺口率。
  • 菲利普斯：π = πe − ε(u−u*) + v，代入即可；注意 u−u* 为负时通胀上升。
  • 多期题：本期 π 自动成为下期 πe，逐期递推。
  • 实际利率：r ≈ i − π。

题型五：开放经济（第十四章）

  • 记账：钱进 → 贷方(+)，钱出 → 借方(−)，储备作平衡项倒推。
  • 实际汇率：ε = eP/Pf，越大越贵、净出口越少。
  • BP：令 NX = F；上方顺差、下方逆差。
  • 政策效果：直接套"固财浮货"，并写出含"升值/贬值 → 净出口"的传导链。

展开参考答案
1. GDP 按国土原则（境内生产），GNP 按国民原则（本国国民生产）；GNP = GDP + 来自国外的要素收入净额。
2. 二手房本身不计（非当期生产，但中介佣金计入）；股票买卖不计（金融资产转移）；保姆工资计入（市场化服务）；养老金不计（转移支付）；存货增加计入（存货投资）。
3. 5；−4；4；1。
4. 政府购买直接形成需求；转移支付要先给居民，居民只花 β 部分，其余储蓄漏出。
5. IS 向右下（β 大、d 大 → 越平缓）；LM 向右上（k 大越陡、h 大越平）。
6. 流动性陷阱（LM 水平）：货币无效、财政完全有效；古典区域（LM 垂直）：财政完全挤出无效、货币完全有效。
7. 政府支出推高利率、挤掉私人投资；LM 垂直（古典情形）时完全挤出。
8. 价格 P 上升 → 实际货币供给 M/P 下降 → LM 左移 → 收入下降，把这些 (P, Y) 点连起来即 AD。
9. 粘性工资、粘性价格、错觉理论；长期价格与工资充分调整、无错觉，产出回到潜在水平，故垂直。
10. AS 左移 → 价涨量减＝滞胀；扩张会加剧通胀、紧缩会加剧衰退，故需求政策两难，只能辅以供给端政策。
11. 失业率每高于自然率 1 个百分点，实际 GDP 约低于潜在 GDP 2%；长期 PC 是过 u* 的垂线（预期充分调整，通胀与失业无替代）。
12. 固财浮货：固定汇率下财政有效、货币无效；浮动汇率下货币有效、财政无效。三元悖论：资本自由流动、固定汇率、货币政策独立三者不可兼得。
